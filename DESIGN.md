# УТАЩИ ЭТО! (SNATCH IT!) — дизайн-документ v1

Этот файл — единственный источник правды по дизайну. Рабочий (Claude Code) реализует только то, что здесь записано. Если в коде нужно решение, которого тут нет, рабочий спрашивает, а не придумывает.

## 0. Решения дизайнера (поправки к исходной концепции)

| # | Решение | Почему |
|---|---------|--------|
| D1 | `CourtNightService` переименован в **`PurgeNightService`** | «Court» — это «суд», а не «Судная ночь». Имена модулей должны быть понятны через полгода. |
| D2 | **Свои экспонаты физически никогда не покидают музей**, кроме кражи. Перестановка — через подсказку «Переставить» (обмен витринами), уборка — «В хранилище». | Если владелец может вынести свой предмет на карту, появляются десятки путей к дюпу и потере. Меньше состояний — меньше багов. |
| D3 | Предметы на карте **не сохраняются**. Игрок вышел с предметом в руках — предмет исчезает. | Предмет становится «настоящим» (попадает в DataStore) только в момент размещения в музее. |
| D4 | Время Судной ночи считается из `os.time()` (UTC) по конфигу. Все сервера приходят к одному расписанию без MessagingService. | Просто и одинаково на всех серверах. |
| D5 | Владелец вышел во время Судной ночи → его профиль **держится загруженным до конца события**, музей остаётся на сервере и его можно грабить. | Иначе выход из игры станет бесплатной неуязвимостью. |
| D6 | Лимит потерь: **максимум 2 экспоната** у одного владельца за одну ночь. Музеи с < 3 экспонатами — неприкосновенны. | Кража должна жалить, но не уничтожать прогресс. Новичков не грабят. |
| D7 | Перехват вора — **«Подсечка»** (кнопка, радиус 6 стадов, перезарядка 8 с), без оружия. | Погоня вместо боя, подходит для любого возраста. |
| D8 | Имена предметов не должны совпадать с модификаторами. «Золотая тапка» → «Пушистая тапка», «Огромная кружка» → убрана, «Золотой метеорит» → «Звёздный метеорит». | Иначе «Золотая Золотая тапка». |
| D9 | Для проверки есть **режим разработчика**: Судная ночь длится 2 мин и запускается командой. | Ждать 14:00 UTC для теста невозможно. |

### ⚠️ Главный риск дизайна — частота Судной ночи
Средняя сессия в Roblox — 20–40 минут. При двух событиях в сутки большинство игроков **ни разу не увидят** главную механику. Расписание — только в конфиге (`GameConfig.PurgeNight.ScheduleUTC`). Рекомендация: после первого плейтеста попробовать каждые 2–3 часа (например, `{"00:00","03:00",…}`) и сравнить удержание. Решение принимаем по данным, не на глаз.

## 1. Состояния экземпляра предмета

```
OnMap ──pickup──▶ Carried(by) ──display──▶ Displayed(owner, slot) ◀──swap──▶ Stored(owner)
  ▲                  │drop/leave                │
  └──────────────────┘                          │ (только Судная ночь)
                                                ▼
                         Lifting(thief) ──done──▶ Stolen(thief, from) ──deliver──▶ Displayed/Stored(thief)
                              │cancel                 │drop / end / leave / tackle
                              ▼                       ▼
                         Displayed(owner)       Dropped(from) ─(20 с / возврат)─▶ Displayed(owner)
```

- Каждый экземпляр имеет `uid` = `HttpService:GenerateGUID(false)`, выдаётся при появлении на карте.
- Сервер держит одну таблицу `ItemRegistry[uid] = {state, ...}`. Любой переход — одна функция, которая проверяет текущее состояние. Невозможный переход = отказ + лог.
- Только состояния `Displayed` и `Stored` попадают в сохранение.

## 2. Схема сохранения (Profile v1)

```lua
{
  schema = 1,
  coins = 0,
  museumLevel = 1,             -- 1 → 6 витрин
  items = {                    -- только подтверждённые экземпляры
    [uid] = {
      id = "OldBoot",          -- ключ в Config/Items
      mods = {},               -- {"Golden","Giant"} — этап 3
      place = "slot",          -- "slot" | "storage"
      slot = 3,                -- если place == "slot"
      rot = 0,                 -- поворот на витрине, градусы
      acquiredAt = 0,          -- os.time()
      source = "map",          -- "map" | "raid"
    },
  },
  stats = { delivered = 0 },
}
```
Редкость и стоимость **не хранятся** — вычисляются из конфига по `id` + `mods`. Изменил баланс — изменилось у всех.

## 3. Мир и сервер
- До 8 игроков на сервер. 8 участков-музеев по кругу, в центре — общая карта (площадь, улицы, крыши).
- Участок выдаётся при входе, освобождается при выходе (с учётом D5).

## 5. Баланс Судной ночи (этап 5, для справки)
- Предупреждение 10 мин, событие 10 мин, по умолчанию `14:00` и `20:00` UTC.
- Время снятия с витрины: Common 2 с, Uncommon 3 с, Rare 5 с, Legendary 8 с, Secret 12 с. Укреплённая витрина ур.1/2/3: ×1.5 / ×2 / ×2.5. Снятие прерывается, если вор отошёл > 8 стадов или получил подсечку.
- Вору нужно свободное место (витрина или хранилище) **до начала** снятия.
- Уроненная добыча лежит 20 с; владелец или любой игрок может её «вернуть» (награда за возврат), иначе — автоматический возврат владельцу.
- «Сейф коллекционера»: 1 слот, ставится только до начала ночи, действует всю ночь, перезарядка — до следующей ночи.
- «Главный вор»: 2+ успешные кражи за ночь → подсветка и метка на карте до конца ночи, награда за перехват.

## 6. Передача владения при краже (этап 5 — важно спроектировать заранее)
Оба профиля (вор и жертва) загружены на одном сервере. Внутри сервера передача атомарна (Luau однопоточный, без `yield` между шагами). Риск — падение сервера между двумя сохранениями. Решение — **журнал передач**:

1. `UpdateAsync` в хранилище `Transfers`, ключ `to_<thiefId>`: запись `{transferId, uid, itemData, from, state="pending"}`.
2. Удалить предмет из профиля жертвы → сохранить жертву.
3. Пометить запись `state="victimSaved"`.
4. Добавить предмет вору → сохранить вора → пометить `state="done"`.

При загрузке профиля вора: записи `victimSaved`, которых нет в профиле, — выдать; записи `pending` — отменить (жертва их не потеряла). Порядок выбран так, что худший случай — задержка выдачи, а не дубликат.

## 8. Этапы
1. **Вертикальный срез**: пустой музей (6 витрин), 3–4 тестовых предмета, подбор/перенос/бросок, «Выставить», сохранение и восстановление после перезахода, посещение чужих музеев.
2. 10 предметов, хранилище, перестановка, поворот, презентация при размещении.
3. Редкость, модификаторы, валюта, доход, каталог, расширение музея.
4. Защита (тестовый режим без реальных потерь).
5. Судная ночь, кражи, перехват, журнал передач.
6. Полировка, мобильное управление, звук, плейтест.
