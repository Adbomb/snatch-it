в ту же часть. Таких граней 57 — 46 внутри головы и 11 внутри туловища. Часть — твёрдое тело, поэтому от позы это

6.4 млн пикселей отличаются 3, на 5 единиц из 255 — уровень шума. Сравнение — `optimize/before_after.jpg`.

## Что мешает импорту

Доступно через MCP сейчас:

| Операция | Состояние |
|---|---|
| Загрузка картинок (`upload_image`) | работает — так загружались прежние карты |
| Загрузка FBX через Open Cloud | **закрыта**: Studio отвечает «Scope 'asset:read' has not been granted» |
| Загрузка меша кодом из Studio | невозможна (`CreateAssetAsync` недоступен — проверено раньше) |
| Импорт руками (File → Import 3D) | работает, но это действие в Studio делаете вы |

Последствия любого пути одинаковы: в вашем инвентаре Roblox появятся 27 мешей (или одна модель с ними) и 6 картинок.
Они проходят модерацию и остаются навсегда — удалить нельзя, только архивировать. Игра при этом не публикуется.

Два способа:

1. **Выдать доступ (быстрее).** В Studio: Assistant → настройки → MCP Permissions — включить `asset:read` и
   `asset:write` и разрешить папку `C:\Users\uzhgb\snatch-it\assets`. Дальше я сам загружу один FBX и шесть карт,
   вставлю модель и впишу ID.
2. **Импортировать самому.** File → Import 3D → `assets/models/Boss4_Sphinx_game.fbx`. Карты загружу я, ID мешей
   впишу я.

### План атаки (раннее уведомление)

- Сервер пишет в атрибуты модели тип следующего удара, плановое серверное время начала выпада и номер удара.
- Клиент начинает замах за 0.45 с (лапа) или 0.5 с (хвост + лапа) до этого времени. Урон по-прежнему считает
  только сервер через `HitDelay`.
- Первый удар боя: план публикуется в начале перехода в боевую стойку, за 1.1 с до удара, а не за 0.6. Замах
  не обрезается при задержке сети до 0.65 с (сейчас — до 0.15 с). Время самого удара не меняется.
- Если удар не состоялся (игрок отошёл, бой кончился), замах гаснет обратно в стойку.
