## 2. Что импортировано настоящими MeshPart

**Ничего из нового.** Ни 30 существ, ни Сфинкс пока не стали MeshPart:
- права Open Cloud `asset:read` / `asset:write` не выданы (проверено запросом 2026-11-13 — отказ). Обходить это я не
  стал;
- импорт FBX (File → Import 3D) через MCP невозможен.

Поэтому существа — Part-версия (≤ 40 блоков), Сфинкс — заготовки частей по скелету. Как финальный вид это не годится.
Карты к мешам уже загружены и привязаны.
