# Модель экономики на 84 часа (D56)

Модель, по которой владелец утвердил экономику 10 боссов 2026-11-11 (DESIGN.md, D56). Числа игры лежат в
`src/shared/Config/Progression.luau`, `GameConfig.Defense.HackPrices` и `Config/Catch.luau`; этот каталог — откуда
они взяты и чем их перепроверить. Игра эти файлы не читает.

| Файл | Что это |
|---|---|
| `econ84.py` | Основа: шансы и время поимки, бой, доходы существ из `Config/Items`, расписание дня и ночи. |
| `econ84c.py` | Модель версии 3: 10 уровней музея (до 20 мест), тренировка в подготовку и в Судную ночь (как в коде), защита и взлом, порядок покупок; калибровка (`python econ84c.py` — долго). |
| `econ84c_report.py` | Отчёт по файлу параметров: `python scripts/sim/economy84/econ84c_report.py [файл.json]` (1–2 минуты). |
| `approved.json` | **Утверждённые параметры**: сила боссов, цены гантелей, уровней музея и Бумов, взлом 1B / 10B / 30B / 80B на уровнях 7–10. |
| `report_approved.md` | Отчёт по `approved.json`: обычный игрок приходит к боссам 7 / 8 / 9 / 10 на 14.2 / 28.0 / 56.2 / 84.6 ч. |
| `calibrated_variant_b.json`, `calibration.log` | Итог калибровки (взлом тогда был 2B / 8B / 30B / 80B) и её журнал. |
| `econ84b_design.json` | Параметры до калибровки версии 3 (отчёт показывает «было → стало»). |

Что модель не трогает (условия владельца): скорость тренировки, мощность гантелей, формулу бонуса музея; сила — только
от гантелей; победы над боссами силу не дают; ограничений по календарным дням нет.

`scripts/sim/progression.py` (D29–D31) устарел: читает поля `RarityFirst` / `RarityLast`, которых нет в конфиге с D37.
