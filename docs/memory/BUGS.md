# Известные ошибки и особенности

## Игра
- В Output при старте: `ContentId: rbxassetid://203785492 failed due to: Asset type does not match` (×3).
  Не из нашего кода (в `src/` этого ID нет) — вероятно, плагин или настройки места. Не мешает.
- Замена Plastic на «LegoStuds» действует на всё Plastic, включая части аватаров игроков (пупырышки на теле).
  Пока считается допустимым для LEGO-стиля.
- Интерфейс пока на UIKit/UITokens; переход на Stud-UI (D20) — шаг 8.
- Миграции профиля (D56): каждая миграция привязана к своей схеме, а не к `ProfileTemplate.schema`. До D56
  `TutorialRules.Migrate(data, ProfileTemplate.schema)` срабатывала при `schema == шаблон − 1`: с шаблоном 5 она
  «мигрировала» бы обучение у профилей v4 заново (а v3 — не мигрировала бы вовсе). Теперь — `TutorialRules.Schema`.
  При следующем повышении схемы новую миграцию ставить последней и со своей константой.
- Studio и MCP (2026-11-11): пока монитор спит (долго нет ввода), Studio не отрисовывает кадр — у клиента в Play
  `ViewportSize = 1×1`, интерфейс считает экран нулевым, `screen_capture` и запросы с ожиданием отрисовки виснут по
  тайм-ауту (серверные тесты при этом идут нормально). Лечится без перезапуска: разбудить экран (движение мыши через
  `mouse_event`), затем заново Stop → Play. Проверка: `workspace.CurrentCamera.ViewportSize` на клиенте.
- `require` из MCP даёт отдельную копию модуля: открыть окно контроллера так нельзя — только настоящим вводом
  (`user_mouse_input` по пути кнопки). Функции-замеры между вызовами MCP живут в `_G` клиента.
- Запас защиты (D56) нельзя менять как число (`owned[вид] += 1`): это таблица по уровням; только
  `DefenseRules.Add / Take`. Запись прежнего формата в живом профиле `DataService.Defense` закрепляет за нынешним
  уровнем музея, поэтому перед сменой уровня она обязана быть проверена (`DataService.UpgradeMuseum` делает это сам).
- Stud-UI: 9 собственных текстур набора (`UI.Assets.Studs`, `ShopHeader`, `Basket`, `RobuxCoin`, плашки
  редкостей `UI.Rarities.*.panel`) в нашем месте дают Failure — без них нет пупырышков на кнопках и плашек.
  Из реестра иконок не грузятся 7: Nature/Banana/Banana_1st, Social/Discord/Gamepad_* (5), Social/Twitter/Bird_White.
  Решение D32: плашки и заголовки — Frame + UIGradient + UIStroke, пупырышки — LegoStuds, монета Robux — иконка реестра.
