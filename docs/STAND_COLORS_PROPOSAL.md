# Подставки существ = цвет редкости (UITokens.Rarity) — предложение для всех боссов

Статус: **предложение владельцу 2026-11-25**, ничего не изменено.

## Что сейчас
- Цвет редкости в интерфейсе один и тот же везде — `src/shared/Config/UITokens.luau:31-37` (градиент «светлый → насыщенный»):
  Common D9D7E3 → ADA6B4 (серый), Rare 84CAE8 → 3D8EE0 (синий), Epic E2B0FF → 9A3EF0 (фиолетовый),
  Legendary FFE27A → F5A215 (золото). Его берут плашки, ноша, инвентарь, подписи над предметом, прожектор витрины.
- Подставки существ задаются в Blender и **запекаются в цветовую карту существа** — `scripts/blender/creature_kit.py:95-232`
  (и две старые копии того же кода: `art_oasis.py` босс 4, `art_rats.py` босс 3):

| Редкость | Подставка сейчас | Цвет редкости | Совпадает? |
|---|---|---|---|
| Обычное | бирюза 23606B / 5CC2CC | серый ADA6B4 | нет |
| Редкое | фиолетовый 6B3FB8 + золотой обод | синий 3D8EE0 | нет — фиолетовый это Эпическое |
| Эпическое | гора золота F2C230 | фиолетовый 9A3EF0 | нет — золото читается как Легендарное |
| Легендарное | лазурит 2B4FC2 + золото | золото F5A215 | частично — синее тело читается как Редкое |

- **В игре подставка скрыта у 87 существ из 90** (`CreatureRigs.luau`: `Stand = "hide"`; правила D54/D58).
  Видна только у трёх эпических существ босса 3 с горой золота: RatThrone, SubwayOctopus, ThreeTailEmperor.
  Поэтому расхождение видно прежде всего на рендерах и листах (каталоги, концепты боссов 4–6) и у этих трёх.
- Боссы 1–2 — предметы, а не существа: их подставки — часть дизайна предмета, к редкости не относятся.

## Предложение (рекомендую)
1. **Один источник цвета.** Скрипт читает `UITokens.Rarity` прямо из `UITokens.luau` и отдаёт цвета в Blender — подставки
   и листы концептов берут цвет только оттуда (вписанные вручную копии убираем). Поменяли токен — поменялись подставки.
2. **Новые подставки по редкостям** (форма прежняя, ярусы D39, кольца):
   - Обычное — серая ADA6B4 с каймой D9D7E3;
   - Редкое — синяя 3D8EE0 с каймой 84CAE8, **без золотого обода** (золото оставляем только Легендарному);
   - Эпическое — фиолетовая 9A3EF0 с каймой E2B0FF, вместо горы монет — аметисты;
   - Легендарное — золотая F5A215 / FFE27A с камнями (нынешняя «гора золота» в цвете Легендарного).
3. **Где применить:**
   - босс 6 — сразу в шаге 2 (производство), без повторных загрузок;
   - боссы 4–5 — перерисовать только рендеры и листы каталогов (в игре подставки скрыты — загрузок нет);
   - босс 3 — три эпических с горой золота: оставить исключением («клад Крысиного короля») **или** перекрасить в
     фиолетовый и заново загрузить 3 цветовые карты (только с вашего разрешения).
4. **Плиты добычи на аренах** (отдельно, только код): подсветку плиты красить цветом редкости существа на ней
   (`UITokens.RarityColor`) — на «Леднике» сейчас все плиты голубые.

Объём: 3–4 файла Python (подставки сводятся в один `creature_kit`), скрипт палитры, перерисовка кадров по желанию,
0–3 загрузки. Проверка: скрипт сверяет цвета подставок с `UITokens.Rarity`; лист «по одному существу каждой
редкости рядом с плашками интерфейса»; в Studio — тесты скрытых подставок и Play.

## Вопросы
1. Серая подставка для Обычного — да? (Риск: под белыми и серыми зверями меньше контраста — покажу на рендере.)
2. Золотой обод у Редкого убрать?
3. Три эпических босса 3 с горой золота — оставить исключением или перекрасить и загрузить 3 карты заново?
4. Подсветку плит на аренах красить цветом редкости?
