# Босс 5 «Йети-коллекционер» (Ледник) — каталог ледяной коллекции: 30 существ

Статус: **предложение на утверждение владельцу** (шаг 2 D64, 2026-11-23). После «ок» каталог переносится в
`docs/CATALOG.md` (раздел «Босс 5»), доходы раздаются вокруг средних D56 по «вау»-рангу (отдельное предложение, как
D57), вес — по габаритам готовых моделей (правило D58).

Правила коллекции:
- 30 существ: Common 12, Rare 9, Epic 6, Legendary 3 (D64; Secret — с босса 8).
- Шансы слота D37 для боссов 4–7: Common 52 %, Rare 30 %, Epic 13 %, Legendary 5 %.
- Живые существа из подвижных частей (D54, D55), стиль D39, лицом вперёд.
- Не больше 3 существ одной семьи силуэтов внутри коллекции.
- Повторов с коллекциями боссов 1–4 нет — сверено по именам и образам.
- Без людей и человекоподобных фигур, текста, логотипов, оружия и узнаваемых чужих персонажей.
- «Вау»-ранг — порядок зрелищности внутри редкости (1 — самое зрелищное); по нему доход растёт внутри редкости, как
  у D57.
- ✓ — эскиз есть на утверждённом листе `boss5_v2/3_collection.png`.

## Сверка с боссами 1–4 — что изменено против эскизов

| Эскиз | Повтор | Предложение |
|---|---|---|
| Песец в ушанке | у босса 4 уже две лисы: Фенек-лопоух и Фенек-загадочник | **Заяц в ушанке** — ушанка и образ сохраняются, животное новое |
| Кит-айсберг с деревушкой | у босса 4 есть Кит-бархан (Epic): кит, спина — дюна | **Нарвал-айсберг** — та же деревушка с маяком, другой силуэт (бивень-кристалл) |

Отброшено при составлении, потому что повторяет боссов 1–4:
- кальмар — Подземный осьминог;
- рыба во льду — Рыба-мираж в водяном кубе;
- улитка-иглу — Улитка-метро;
- черепаха-термос — две черепахи босса 4;
- лось — четвёртый в семье «Четвероногий».
