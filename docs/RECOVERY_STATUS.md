# Состояние проекта после блокировки аккаунта Roblox (2026-11-03)

**Что случилось.** 2026-11-02 в 21:28 Roblox заблокировал аккаунт владельца (AdBoMb4IK1) на 7 дней, до
**2026-11-09 21:28**, с формулировкой «sexual content». Причина — две карты цвета, которые Claude загрузил через
Studio MCP для картин коллекции босса 2: «Сотворение Адама» (asset 115188607358965) и «Рождение Венеры» (asset
91016959329136). На обеих картинах обнажённые фигуры. Правило «без обнажённых фигур (модерация Roblox)» было записано
ещё в D38, но для босса 2 его не применили — это ошибка Claude. Апелляции подаёт владелец (срок — до 2027-05-01).

**Главное: игра не потеряна.** Весь код, карта, модели, карты текстур и документы — в репозитории. Карту и предметы
игра строит кодом при запуске (`World/WorldBuilder`, меши — `AssetService:CreateMeshPartAsync` по MeshId из
конфигов). Код Luau не менялся с коммита `4ea4b40`, на котором 2026-11-02 серверные тесты в Studio прошли 32 из 32.
