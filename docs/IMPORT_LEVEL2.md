# Уровень 2 «Барахолка»: что осталось сделать в Roblox Studio (D42, D43)

Код уровня 2 готов и лежит в репозитории: декор (редизайн D44), площадка босса, бой с торговцем, 30 предметов. До импорта
мешей босс и предметы показываются заготовками цвета и размера модели (как было у босса 1 до импорта).
В Studio эта работа ещё **не проверялась**: аккаунт владельца заблокирован Roblox.

## Когда можно начинать
- Только когда Roblox снимет блокировку с аккаунта владельца, и только этим аккаунтом.
- Другой аккаунт для обхода блокировки не использовать и ничего не публиковать, пока блокировка действует.

## 1. Владелец: посмотреть картинки (до любой загрузки)
Открыть и посмотреть глазами 60 файлов `assets/textures/art/<id>_color.png` и `<id>_normal.png` для 30 предметов
из `docs/CATALOG.md` (раздел «Босс 2»). Карты нормалей — сиренево-голубые, это нормально. Если какая-то картинка
вызывает сомнение — не загружать её и сказать Claude.
Запрещённые навсегда ID: 115188607358965, 91016959329136 (их не примет ни один скрипт проекта).

## 2. Claude: загрузить карты (после «ок» владельца)
1. Студия открыта под аккаунтом владельца, `scripts/rojo-serve.ps1` запущен, плагин Rojo подключён.
2. Claude загружает 60 карт через Studio MCP `upload_image` по одной и записывает ID в
   `assets/textures/art/Boss2_maps.json` в виде `{"GoldenBanana": {"color": …, "normal": …}, …}`.
3. `python scripts/bind_maps.py assets/textures/art/Boss2_maps.json` — записи в `Config/ItemModels`.

Карты торговца (голова, туловище, руки и ноги) уже загружены до бана (`assets/textures/art/IDS.md`) —
перед работой проверить, что они открываются в Studio; если нет — загрузить заново так же.

## 3. Владелец: импорт мешей (одно действие, через MCP его сделать нельзя)
В Studio: **File → Import 3D**, по очереди два файла, настройки как у босса 1:
1. `assets/models/Art_Boss2_MadFinds.fbx` — 30 мешей `Art_<id>`.
2. `assets/models/Boss2_Trader.fbx` — 12 частей `Boss2_Trader<Карта>_<Часть>`.

После импорта сказать Claude «импорт готов» — дальше всё делает Claude.

## 4. Claude: привязка и проверка
1. Собрать MeshId импортированных MeshPart в `assets/models/Boss2_meshids.json` (имя объекта → MeshId)
   и перенести импортированные модели в `ServerStorage.ImportedModels`, как у босса 1.
2. `python scripts/bind_meshes.py assets/models/Boss2_meshids.json` (если меши повёрнуты — `--item-turn` /
   `--boss-turn 2=…`), затем `python scripts/make_looks.py` и `python scripts/check_project.py`.
3. Проверки без Studio: `lune run scripts/lune/check_config.luau`, `lune run scripts/lune/check_world.luau`.
4. Проверки в Studio (ни одна ещё не делалась):
   - серверные тесты (`ServerTests`) — все, включая новые тесты торговца;
   - `World/FaceCheck` на предпросмотре: видимых пар 0;
   - Play: вход в уровень 2, плашка, голограмма, бой с торговцем (поражение и победа), предметы на площадке,
     надписи на 15 вывесках, прожекторы на боссе, свет павильонов и сундука; оформление D44 с камеры игрока
     (сравнить с рендерами), босс в бою не заходит в декор; телефон (эмулятор) — частота кадров на уровне 2;
   - снимки уровня владельцу.
5. Обновить `docs/memory/*`, `docs/RECOVERY_STATUS.md`, коммит и push.
